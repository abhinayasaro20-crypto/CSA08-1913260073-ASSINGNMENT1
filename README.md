## Project Description
This repository contains the complete solutions and documentation for Assignment 1 of the SIMATS Online Programming Lab ("Design, Implement and Validate a Payment Calculator for a Village Milk Co-operative"). The project explores Python fundamentals, data types, floating-point precision error handling, structured scaling, and seasonal pricing models.
